# Third-party notices — M4K3R local release candidate

This file records the provenance and license material identified for the installed release dependencies and bundled library data. Full notices are retained in `third_party/licenses/`; packaged releases additionally contain the generated `third_party/dependencies/` license inventory and `third_party/sources/` archives. Installed npm packages retain their original files in `node_modules`.

This is an attribution and packaging record, not a legal determination that the combined application is suitable for public redistribution. The repository has no first-party `LICENSE` grant; this work does not choose one on the owner's behalf. The local release is an unpublished release candidate. Public distribution, commercial licensing decisions and the treatment of the combined work require an owner decision and review of the applicable terms below.

## KiCad-derived library portions

The included generic catalog contains transformed KiCad symbol/footprint portions. Their `symbol.source` and `footprint.source` fields retain the originating `Library:Name` attribution. These portions originate with the **KiCad community / KiCad libraries contributors**, under **CC-BY-SA 4.0 with the KiCad libraries exception**. The complete license and exception are retained in `third_party/licenses/KiCad-library-license.md` and `CC-BY-SA-4.0.txt`.

M4K3R changes include parsing native KiCad library data into the project's JSON geometry format, selecting a single unit where applicable, mapping pads/pins and adding application properties and generic physical envelopes. `third_party/library-attribution.json`, generated for each release, lists every included part and its source fields. The original import did not record upstream Git commit IDs; the record does not invent a revision. On-demand imports currently read the official libraries' `master` branch and are cached in the user's home, not baked into the release.

The upstream exception concerns electronic designs and generated design files. It expressly does not apply to redistribution of library collections or modified collections. Included KiCad-derived catalog portions retain the upstream attribution, share-alike terms and license documents. This notice does not assign a license to unrelated first-party generic physical data or determine the legal treatment of every possible exported design.

Primary library license sources:

- [KiCad symbols license](https://gitlab.com/kicad/libraries/kicad-symbols/-/blob/master/LICENSE.md)
- [KiCad footprints license](https://gitlab.com/kicad/libraries/kicad-footprints/-/blob/master/LICENSE.md)
- [KiCad library licensing explanation](https://www.kicad.org/libraries/license/)

The **ESP32-C3-DevKitM-1 footprint** has a separate origin: **Espressif Systems / contributors to `espressif/kicad-libraries`**, rather than the KiCad community footprint collection. The catalog's `footprint.source` retains that distinction; its symbol comes from KiCad `RF_Module:ESP32-C3-DevKitM-1`. The [Espressif repository license](https://github.com/espressif/kicad-libraries/blob/main/LICENSE.md), checked on 2026-10-18, also grants CC-BY-SA 4.0 with an electronic-design/generated-file exception and states that these are the same conditions as KiCad's official libraries. Its complete notice is retained separately in `third_party/licenses/Espressif-KiCad-library-license.md`, alongside the CC-BY-SA 4.0 text. The [original footprint](https://github.com/espressif/kicad-libraries/blob/main/footprints/Espressif.pretty/ESP32-C3-DevKitM-1.kicad_mod) was converted to M4K3R pad/outline JSON geometry. The import used `main` and did not record an upstream commit, so this notice does not claim an exact historical revision. This attribution concerns the footprint library data; the generic estimated physical envelope has its own source field.

Manufacturer/product names identify interfaces or example parts; the generic estimated physical catalog is not a manufacturer endorsement or a vendor CAD/datasheet distribution. User-created/imported parts remain subject to their own source terms and are excluded from the local release package.

## Other JavaScript dependencies

The release generator records every actually installed package's name, version, declared license, repository URL and copied LICENSE/COPYING/NOTICE/ThirdPartyNotices files under `third_party/dependencies/`. This includes React, Express, Vite/tsx, Zod, Immer, Zustand, Monaco Editor, esptool-js, fflate, polygon libraries, MCP SDK and their installed transitive dependencies. The inventory is generated from the installed versions rather than inferred from semver ranges. Its JSON also identifies packages without a top-level license file for follow-up; original package contents are retained in `node_modules`.

The inventory covers development packages when they are present in the host bundle too. Browser/editor notices, including Monaco's ThirdPartyNotices, are copied when supplied by the package. There are no telemetry credentials, project homes, Arduino toolchains, ESP emulator binaries, browser binaries or personal imported-part caches intentionally included.
